# zooma
A pretty basic clone of [boomer](https://github.com/tsoding/boomer) for X11 and Wayland.

### Runtime Dependencies
- ``scrot`` (for X11)
- ``grim`` (for Wayland)
- ``spectacle`` (optional, for KDE specifically)
- ``glfw``
- ``libgl``
- ``libx11``
- ``libxcursor``
- ``libxi``
- ``libxinerama``
- ``libxkbcommon``
